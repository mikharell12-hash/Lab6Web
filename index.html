    E5

    Eksperimen script tanpa defer

    Penjelasan konsep

    Jika file JavaScript dipanggil di bagian <head> tanpa defer, script dapat berjalan sebelum elemen HTML selesai diparsing. Akibatnya, getElementById() atau querySelector() bisa menghasilkan null. Atribut defer menunda eksekusi hingga HTML selesai diparsing.

    Praktikum selesai. Semua contoh berjalan di browser dan menggunakan JavaScript tanpa library eksternal.
